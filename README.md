# mazeBot
A mini bot that performs DSA and Machine learning algorithms 

## Dependencies

### Software
- PlatformIO
- Arduino framework for ESP32
- C++

### PlatformIO Libraries
- Adafruit GFX Library
- Adafruit SSD1306

### Hardware
- Freenove ESP32-S3 WROOM
- TB6612FNG motor driver
- 2 TT DC motors
- 5-channel TCRT5000 line sensor
- SSD1306 0.96" OLED display
- 3 push buttons
- 2WD robot chassis
- 4xAA battery pack
